# ⚔ Stickman Fight

Juego de pelea de stickmen con 7 personajes únicos, habilidades especiales y modo mejor de 3 rondas.

## 🎮 Cómo jugar

Abre `index.html` en el navegador o visita la versión publicada en GitHub Pages.

### Controles

| Acción | Tecla |
|--------|-------|
| Mover | `A` / `D` |
| Saltar | `W` |
| Agacharse | `S` |
| Puñetazo | `J` |
| Patada | `K` |
| Uppercut | `U` |
| Especial | `I` (requiere medidor lleno) |
| Bloquear | `L` |
| Reiniciar | `R` |

## 🥊 Personajes

- **ROCKY** — Piel de hierro (-15% daño) · Especial: Meteoro
- **BLAZE** — Doble salto · Especial: Furia Fugáz
- **TITAN** — Roca viva (-25% daño, sin retroceso) · Especial: Terremoto
- **SHADOW** — +30% velocidad al retroceder · Especial: Corte Umbrío
- **FROST** — Sus golpes ralentizan · Especial: Ventisca (proyectil)
- **BOLT** — Rayo extra cada 4 golpes · Especial: Tormenta
- **PHOENIX** — Regenera vida · Especial: Nova Solar (cura + daño)
